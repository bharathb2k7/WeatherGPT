# 🌦️ WeatherGPT

### AI-Powered Weather Intelligence

WeatherGPT is an AI-powered weather assistant that combines real-time weather data with intelligent, actionable recommendations.

It helps farmers, fishermen, commuters, travelers, and everyday users understand not just **what the weather is**, but **what they should do about it**.

## ✨ Features

- 🌦️ Real-time weather information
- 🤖 AI-powered weather advice
- 🚨 Weather alerts and safety warnings
- 🎙️ Voice interaction
- 🌐 English and Telugu support
- 📍 Location-based weather intelligence
- 🌱 Farmer-focused recommendations
- 🎣 Fishing safety insights
- 🚗 Commuter weather guidance
- 🔎 AI + web-grounded information
- 📱 Responsive modern interface

## 🛠️ Tech Stack

- React
- TypeScript
- Gemini API
- Open-Meteo
- Firebase
- Google AI Studio
